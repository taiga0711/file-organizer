# file-organizer

拡張子ごとにファイルを自動で振り分ける Python ツールです。

## 概要

指定したフォルダの中のファイルを、画像・PDF・Word・Excel などの種類ごとにフォルダ分けします。
ダウンロードフォルダのように、いろいろなファイルがたまったフォルダの整理に使えます。

## 特徴

- **確認モード(DRY_RUN)付き**: 初期設定では「何が起きるか」を表示するだけで、ファイルは動かしません。内容を確認してから本番実行できます
- **上書きしない**: 移動先に同名のファイルがあるときは、`photo_1.jpg`、`photo_2.jpg` のように番号を付けて保存します
- **大文字の拡張子にも対応**: `.JPG` と `.jpg` を同じ種類として扱います
- **安全な対象選び**: フォルダや隠しファイル(`.` で始まるファイル)は動かしません
- **追加のインストール不要**: Python の標準ライブラリだけで動きます
- **AIの使用の可否**:　AIを活用しながら学習して作成しました

## 動作環境

- Python 3.8 以上

## 使い方

1. `file_organizer.py` をダウンロードします
2. 同じ場所に `test_folder` というフォルダを作り、整理したいファイルを入れます
3. ターミナルで次を実行します

   ```
   python file_organizer.py
   ```

4. 表示された内容を確認します(この時点ではファイルは動きません)
5. 問題なければ、`file_organizer.py` の `DRY_RUN = True` を `DRY_RUN = False` に変更して、もう一度実行します

## 実行例

```
a.jpg  →  画像/a.jpg
memo.txt  →  テキスト/memo.txt
report.pdf  →  PDF/report.pdf

3 件 確認のみ(ファイルは移動していません)
```

`DRY_RUN = False` で実行すると、最後の表示が「3 件 移動完了」に変わり、`test_folder` の中に `画像`、`テキスト`、`PDF` フォルダが作られてファイルが移動します。

## 振り分けルール

| 拡張子 | 振り分け先 |
|---|---|
| .jpg .jpeg .png .gif | 画像 |
| .pdf | PDF |
| .docx .doc | Word |
| .xlsx .xls | Excel |
| .csv | CSV |
| .pptx | PowerPoint |
| .txt | テキスト |
| .zip | 圧縮ファイル |
| .mp4 .mov | 動画 |
| .mp3 | 音声 |
| 上記以外 | その他 |

## カスタマイズ

`file_organizer.py` の上部にある設定を変更できます。

- `TARGET_DIR`: 整理するフォルダ
- `DRY_RUN`: `True` で確認のみ、`False` で実際に移動
- `CATEGORIES`: 拡張子と振り分け先フォルダの対応表。行を追加すると、対応する種類を増やせます

## 注意

- 移動したファイルを元に戻す機能はありません。大切なファイルを整理するときは、先にバックアップをとり、必ず確認モードで内容を確かめてください
- 最初は `test_folder` のようなテスト用のフォルダで試すことをおすすめします
